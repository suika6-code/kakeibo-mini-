# かんたん家計簿（試作品）

自分のパソコンの中だけで動く、最小構成の家計簿アプリです。銀行・証券口座とは連携しません。
**試作品なので、最初は架空のデータで試してください。**

## 起動方法

ブラウザの暗号機能を確実に使うため、「このパソコンの中だけで見られる簡易サーバー」で開きます。
Python（プログラム実行環境）が必要です。Mac には通常入っています。Windows では入っていなければ https://www.python.org/ から入れてください。

- **Windows**：`start-windows.bat` をダブルクリック
- **Mac**：`start-mac.command` をダブルクリック（初回は右クリック →「開く」が必要な場合があります）
- 黒い画面が開いたら、ブラウザ（Chrome / Edge / Safari / Firefox）で **http://127.0.0.1:8000/** を開きます
- 終わるときは、ブラウザを閉じ、黒い画面で `Ctrl + C` を押して閉じます

手で起動する場合（このフォルダで）：

```
python3 -m http.server 8000 --bind 127.0.0.1
```

`--bind 127.0.0.1` は「このパソコンからだけ接続できるようにする」指定です。消さないでください。

### 注意

- 記録は「ブラウザ × 住所（http://127.0.0.1:8000）」ごとに保存されます。**別のブラウザや、番号（8000）を変えて開くと、記録は見えません**（消えたわけではありません）。
- `index.html` を直接ダブルクリックしても Chrome では動きましたが、保存場所が上とは別になります。いつも同じ開き方をしてください。
- ブラウザの「閲覧履歴データの削除（Cookie とサイトデータ）」をすると記録も消えます。定期的にバックアップを書き出してください。

## アプリとして使う（おすすめ）

一度インストールすると、デスクトップやアプリ一覧の「家計簿」アイコンから専用の画面で開けます。
**2回目からは起動用ファイル（黒い画面）も不要**です。アプリの部品をパソコンの中に保管しておくためです。

1. 上の「起動方法」で一度開き、パスワードを入れて解除します。
2. 画面下の「アプリとしてインストール」を押します。ボタンが出ないときは次の方法で追加します。
   - Chrome / Edge：アドレスバー右端のインストールのマーク（画面にパソコンと矢印の絵）
   - Mac の Safari：「ファイル」→「Dockに追加」
3. 以後はアイコンから開きます。記録はブラウザで開いていたときと同じものです。

- アプリを**更新**したときだけ、起動用ファイルを動かしてからアイコンで開いてください（新しい部品に入れ替わります）。
- アンインストールしても記録は消えません。記録を消すのはブラウザの「サイトデータの削除」です。
- Firefox はアプリとしてのインストールに対応していません。

## 使い方

1. 初回に解除用パスワード（10文字以上）を決めます。**忘れると記録もバックアップも開けません。**
2. 「支出／収入」を選び、金額を入れ、カテゴリのボタンを押して「記録する」。
3. 月ごとに予算を設定すると「残り予算 ＝ 予算 − その月の支出合計」が出ます（収入は含めません）。
4. ロック中は、パスワードを入れて Enter キーを押すだけで解除できます（開いた時点で入力欄が選ばれています。「表示」で入力中の文字を確認できます）。
5. 「暗号化バックアップを書き出す」でファイルを保存。復元には、そのとき使っていたパスワードが必要です。

## 保存の仕組み

| 項目 | 内容 |
|---|---|
| 暗号化 | AES-GCM 256ビット（標準の暗号。改ざんも検出） |
| 鍵の作り方 | PBKDF2-SHA256、600,000回（パスワードから鍵を作る標準方式。総当たりを遅くする） |
| 使う機能 | ブラウザ標準の Web Crypto API（独自の暗号は作っていません） |
| 保存先 | ブラウザの localStorage（暗号文だけ） |
| 保存しないもの | パスワード、鍵 |
| ロック | 開き直したとき、「ロックする」ボタン、15分間操作がないとき |
| 通信 | CSP（ブラウザへの指示）で外部との通信・外部ファイルの読み込みを禁止 |

## ファイル構成

- `index.html` … 画面
- `style.css` … 見た目
- `js/calc.js` … 計算と入力チェック
- `js/crypto-store.js` … 暗号化と保存
- `js/app.js` … 画面の動き
- `js/pwa.js` … アプリとしてインストールする機能
- `sw.js` … アプリの部品を手元に保管し、簡易サーバーなしでも開けるようにする仕組み（記録は扱わない）
- `manifest.webmanifest`、`icons/` … アプリ名とアイコン
- `start-windows.bat` / `start-mac.command` … ローカル起動用
- `tests/` … 開発用の自動テスト（アプリの動作には不要）
  - `node tests/calc.test.js`
  - `node tests/e2e.test.js`、`node tests/pwa.test.js`（Playwright と Chrome が必要）

## 安全性について（正直な説明）

- 自動テストで「保存領域とバックアップに平文が残らない」「外部通信がない」ことは確認しましたが、**専門家による安全性の審査はしていません。**
- パソコン自体がウイルスに感染している場合や、解錠中に他人が画面を見る場合は守れません。
- 解錠中は、記録がブラウザのメモリ上に読める形で存在します。ロックすると参照を捨てますが、メモリから確実に消えることまでは保証できません。
- 弱いパスワードは総当たりで破られる可能性があります。長く推測されにくいパスワードにしてください。
